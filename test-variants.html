🎨 Design Features

  • Black background (#000000) with pink accents (#ec4899)
  • Gradient modal background (#0a0a0a → #1a0a14)
  • 3px pink borders on all modals
  • Backdrop blur effect (10px)
  • Smooth animations (fadeIn, slideUp, pulse)
  • Hover effects with scale transforms
  • Selected state with checkmarks (✓)
  • Responsive breakpoint at 768px

📱 Mobile Testing

To test responsive design:

  1. Open browser DevTools (F12)
  2. Toggle device toolbar (Ctrl+Shift+M)
  3. Select a mobile device (iPhone, Galaxy, etc.)
  4. Test all features on mobile view
  5. Verify buttons stack vertically
  6. Check that swatches are appropriately sized
