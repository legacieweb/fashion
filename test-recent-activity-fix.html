Testing Guide

Test 1: User Dashboard - Recent Activity

  1. Login as a user who has placed orders
  2. Navigate to Dashboard (loads automatically)
  3. Check the "Recent Activity" section on the right side
  4. Verify it shows your actual orders (not placeholder data)
  5. Check that status colors match order status
  6. Verify time elapsed is displayed correctly
  7. Confirm order reference numbers are shown
Open User Dashboard

Test 2: Admin Panel - Color Variants

  1. Login as admin
  2. Navigate to "Orders" section
  3. Check each order's item list
  4. Verify color variant shows with 🎨 icon
  5. Verify size shows with 📏 icon
  6. Check that layout is clean and readable
  7. Test in both light and dark mode
Open Admin Panel
